# Wikipedia Editing Standards

A platform-neutral AI skill that digests English Wikipedia's rules: neutrality, verifiability, no original research, notability, biographies of living people, copyright, reliable sources, style, citations, and editor conduct.

## Files
- `SKILL.md`: the full skill
- `COMPACT_INSTRUCTIONS.txt`: a short version for platforms with instruction length limits

## How to use
- **Claude:** upload as a skill, or paste `SKILL.md` into a Project
- **ChatGPT:** paste `COMPACT_INSTRUCTIONS.txt` into a Custom GPT's instructions and upload `SKILL.md` as a knowledge file
- **Gemini:** paste `SKILL.md` into a Gem
- **Kimi and others:** paste `SKILL.md` as the system prompt

## Important
English Wikipedia (as of 2026) prohibits LLM-generated article content. This skill is built for explaining, planning, auditing and coaching human editors, not for generating paste-ready articles. Rules change, so check the live pages.
