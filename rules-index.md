# Rule index

Starter index of the main Wikipedia policy and guideline pages. Open any shortcut at `https://en.wikipedia.org/wiki/<shortcut>`.
This is not the complete list. The official, complete list is [WP:LPG](https://en.wikipedia.org/wiki/WP:LPG).
Running `python tools/check_updates.py --listing --write` (or the weekly GitHub Action) replaces this file with a version that includes each page's latest revision id and edit time.
